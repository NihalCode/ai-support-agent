# Deployment Guide (Build App)

## Preview vs production

| Target | Approval | Use |
|--------|----------|-----|
| `preview` | Required | Share WIP builds |
| `production` | Required + higher risk | Live users |

## Readiness checks

Before deploy, the Deployment Agent verifies:

- `package.json` has a `build` script
- `.env.local.example` exists
- `vercel.json` present (generated by templates)
- `VERCEL_TOKEN` set (otherwise mock deploy)

## Mock mode

When `TEST_MODE=true` or `VERCEL_TOKEN` is missing:

- Build runs return mock success output
- Deploy returns `https://mock-preview.vercel.app/apps/{id}` labeled as mock

## Troubleshooting

| Failure | Fix |
|---------|-----|
| Build failed | Open terminal output in Build App workspace; fix generated code |
| Missing env | Copy `.env.local.example` → `.env.local` in generated app folder |
| Vercel CLI not found | Run `npm i -g vercel` or use `npx vercel` |
| 403 on approve | Disable `SUPPORT_AGENT_READ_ONLY` for write actions |
